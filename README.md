# Contrastive Thinking Decoding

Project page for Contrastive Thinking Decoding: Steering Answer Generation in Reasoning Models, NeurIPS 2026.

https://kthyeon.github.io/contrastive-thinking-decoding/

The paper and research demo video are not released. This repository contains the project website, not the PDF or experimental implementation.

## Development

Open index.html directly or serve this directory. No build step or dependencies are required. Edit index.html, style.css and script.js. PNG assets are in the repository root.

GitHub Pages serves the main branch root. .nojekyll disables Jekyll processing. The interactive example is illustrative rather than recorded inference. Reported examples are attributed to the paper; excerpts and paraphrases are labeled.
